# 《大隋唐：天下棋局》

> [!abstract] 体量
> 移动/PC SLG，赛季制，单赛季 60—90 天

> [!quote] 一句话
> 你不是李世民，也不是李密；你是一个在隋末乱世里招兵买马、结交豪杰、选择阵营的势力主。

## 设计支柱

- 四角棋盘：关中、中原、河北、江淮四大赛区，资源、兵种、地形差异明显。
- 英雄不是卡牌，是“人”：每个武将有能力、欲望、忠诚、关系网，会因事件离队、反叛、结义。
- 粮道即命脉：运河、粮仓（兴洛仓、黎阳仓、洛口仓）是核心争夺点。
- 阵营选择：隋廷、瓦岗、李唐、洛阳郑、河北夏、定杨、江淮，各有独立科技树与结局。
- 名场面事件：四平山会盟、虎牢关之战、玄武门之变，以全服事件形式出现。

## 核心系统

| 系统 | 设计 |
|---|---|
| 武将招募 | 通过“义气/名望/利益/仇恨”四种关系招募；单雄信无法被李唐直接招募。 |
| 兵种 | 府兵、玄甲骑、瓦岗长枪、河北步兵、江淮水军、突厥弓骑、隋朝弩机。 |
| 城池 | 长安、洛阳、太原、幽州、江都、瓦岗、金墉、乐寿、江陵、丹阳等，各有特色建筑。 |
| 粮道 | 控制运河/粮仓，决定远征上限；断粮可引发营啸。 |
| 联盟 | 贾柳楼式结义：共享视野、借兵、合击，但背叛会触发“割袍”事件。 |
| 赛季剧本 | S1“隋失其鹿”、S2“瓦岗内乱”、S3“虎牢关”、S4“玄武门”、S5“贞观远征”。 |

## 商业化注记

- 卖“外观/名马/兵器皮肤”，不卖数值碾压；武将靠赛季事件解锁。
- 赛季通行证以“人物列传”为单位，完成列传解锁专属兵种/计策。
- 避免抽卡同质化：每个武将一张“关系网”，抽到不等于能用，需经营忠诚。

## 神魔层

> [!tip] 事件系统，不是数值挂
> 星象/香火/雷劫/地府/龙族都做成“事件与资源”，不要直接加攻击力。

- **天时**：龙族行雨/洪水/旱灾；季节与粮道。
- **星象**：紫微/二十八宿/三十六天罡的阵营倾向；影响招募/忠诚/战斗。
- **香火**：神明强度=人间香火；拆庙/灭佛/战乱会削弱神魔阵营。
- **地府**：寿命/复活/转世；改命要“替寿”，不是免费复活。
- **金锁**：全服事件；十三关按赛季逐步开放。
