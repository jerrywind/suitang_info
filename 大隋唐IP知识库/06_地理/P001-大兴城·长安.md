# 大兴城 / 长安

> [!abstract] 速览
> - **类型**：都城
> - **今地 / 对应**：陕西西安
> - **区域**：关中
> - **地形**：关中平原，渭水之南，八水环绕，四面关隘

## 战略价值

隋唐帝国的政治中心。宫城—皇城—外郭城三重结构，朱雀大街贯穿南北，东西两市汇聚天下财富。
