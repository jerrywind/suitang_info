## 版本对照

| 版本 | 名单 / 差异 | 说明 |
|---|---|---|
| 《说唐》前期 | 单雄信、秦琼、王伯当、程咬金、邱瑞 | 邱瑞为猛虎大将军 |
| 《说唐》后期（本库） | 单雄信、秦琼、王伯当、程咬金、罗成 | 邱瑞换成罗成 |
| 《隋唐演义》/《隋唐英雄传》 | 单雄信、秦琼、王伯当、程咬金、罗成 | 与后期版同名单 |
| 评书版 | 单雄信、秦琼、程咬金、王伯当、谢映登 | 旧版/评书常见 |
| 其他版本 | 王君可、尤俊达、翟让等可替换第 5 席 | 单雄信、王伯当全版本固定 |

## 版本与争议

- 单雄信、王伯当在所有版本中都是瓦岗五虎；秦琼、程咬金在多数版本中有。
- 第 5 席变化最大：邱瑞（《说唐》前期）、罗成（后期/《隋唐演义》）、谢映登（评书）、王君可/尤俊达（其他版本）。
- 五虎的“虎”是山寨/义军座次，不是全国武力排名；与十三杰、四绝、四猛有重叠。
- 人物小传里的“瓦岗五虎将”是各版本旧称；本库主表采用罗成版，谢映登/王君可/尤俊达等的五虎称号属于异说版本。
