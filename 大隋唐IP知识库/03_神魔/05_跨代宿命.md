# 跨代宿命

> [!quote]
> 同一批神，换一身皮，再打一次。

## 金鹏—雷尊：杀神者死于雷

> [!abstract] 公式
> 封神旧怨 → 金鹏下凡（李元霸）→ 雷尊下凡（宇文成都）→ 紫金山杀雷尊 → 雷劫/锤落

**步骤**：封神大战，闻仲入雷部 → 金翅大鹏与雷部结怨 → 李元霸/宇文成都降生 → 紫金山决战 → 雷劫归位 → 《说岳》大鹏再下凡（跨文本）

**主题**：自由神力 vs 天条；杀神者，必被天条追杀。

> [!tip] 改编
> 短剧首尾闭环；无双做“雷劫”终极关；SLG做“雷部通缉”事件。

## 青龙四世：被辜负者的复仇

> [!abstract] 公式
> 单雄信（反唐）→ 盖苏文（乱辽东）→ 苏宝同/薛刚（反西凉/反武周）→ 安禄山（乱盛唐）

**步骤**：单雄信被斩，青龙怨起 → 盖苏文作乱辽东 → 苏宝同/薛刚再反 → 安禄山发动安史之乱

**主题**：义气被辜负后，会变成跨代的恨。

> [!tip] 改编
> 分四季反派；每季换皮不换眼；最终由白虎星/郭子仪了结。

**相关**：[[03_神魔/01_神魔谱系/M007-青龙星|青龙星]]、[[01_人物/C008-单雄信|单雄信]]、[[03_神魔/01_神魔谱系/M031-盖苏文|盖苏文]]、[[03_神魔/01_神魔谱系/M033-苏宝同|苏宝同]]、[[03_神魔/01_神魔谱系/M034-安禄山|安禄山]]


## 白虎三投唐：救唐者的宿命

> [!abstract] 公式
> 罗成（万箭穿心）→ 薛仁贵（被儿子误射）→ 郭子仪（功高善终）

**步骤**：罗成救唐，死于自己人陷害 → 薛仁贵救唐，死于至亲误伤 → 郭子仪救唐，交出兵权，善终

**主题**：救唐者如何不被唐辜负？答案是：活到能交出兵权。

> [!tip] 改编
> 三段式人物弧线；同一杆枪/白马/白袍；最后一集“交兵权”是高潮。

**相关**：[[03_神魔/01_神魔谱系/M008-白虎星|白虎星]]、[[01_人物/C004-罗成|罗成]]、[[03_神魔/01_神魔谱系/M032-薛仁贵|薛仁贵]]、[[03_神魔/01_神魔谱系/M035-郭子仪|郭子仪]]


## 紫微—二十八宿：被前朝伤透的功臣

> [!abstract] 公式
> 刘秀杀姚期/逼邓禹 → 二十八宿拒保紫微 → 下凡为十八路反王 → 紫微统一

**步骤**：云台二十八将含冤 → 二十八宿拒绝下凡 → 玉帝改派三十六天罡 → 二十八宿下凡反唐 → 紫微收束天下

**主题**：开国功臣的恐惧：怕的不是敌人，是下一个皇帝。

> [!tip] 改编
> 给每个反王一个“前世闪回”；SLG做“星宿阵营”选择。

**相关**：[[03_神魔/01_神魔谱系/M001-紫微大帝|紫微大帝]]、[[01_人物/C011-李世民|李世民]]


## 天蓬线：左天蓬与猪八戒

> [!abstract] 公式
> 天蓬元帅（西游）→ 左天蓬秦琼（隋唐）→ 猪八戒（取经）

**步骤**：天蓬元帅掌管天河 → 左天蓬下凡为秦琼 → 天蓬被贬/错投猪胎 → 猪八戒随唐僧取经 → 两线在“神魔大隋唐”同台

**主题**：同一个神格，一半是门神，一半是喜剧。

> [!tip] 改编
> 短剧喜剧插件；SLG“天蓬”双形态；不要抢历史主线。

**相关**：[[03_神魔/01_神魔谱系/M005-左天蓬|左天蓬]]、[[01_人物/C005-秦琼|秦琼]]、[[03_神魔/01_神魔谱系/M024-天蓬元帅·猪八戒|天蓬元帅 / 猪八戒]]


## 关公—智者—玉泉山：刀魂的归处

> [!abstract] 公式
> 关羽败亡 → 玉泉山显圣 → 智者大师度化 → 伽蓝菩萨 → 魏文通学刀

**步骤**：关羽败走麦城 → 英灵玉泉山显圣 → 智者大师授戒 → 关公成为伽蓝 → 刀意传魏文通

**主题**：刀可以杀人，也可以护法；关键看握刀的人。

> [!tip] 改编
> 玉泉山单元剧；无双“刀魂”关卡；SLG武庙系统。

**相关**：[[03_神魔/01_神魔谱系/M025-关公英灵|关公英灵]]、[[03_神魔/01_神魔谱系/M026-智者大师|智者大师]]


## 哪吒—裴元庆：火神的少年劫

> [!abstract] 公式
> 哪吒下凡 → 裴元庆降生 → 锤震成都 → 火雷阵身亡 → 归位

**步骤**：哪吒领命下凡 → 裴元庆少年成名 → 四平山接三锤 → 庆坠山火雷阵 → 火神归位

**主题**：少年神太亮，所以烧得最快。

> [!tip] 改编
> 视觉做“银锤+火”；游戏做“少年形态/哪吒形态”双形态。
