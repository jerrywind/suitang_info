## 这是什么

一套为**短剧、无双动作游戏、SLG**三端改编准备的大隋唐内容底稿：人物、事件、器物、地理、势力、榜单、神魔谱系与改编方案，全部以 Markdown 笔记 + 双链 + 标签组织，可继续生长。

## 三种读法

1. **史实线**：按 `02_事件/` 的时间顺序读，再进 `06_地理/` 看地理约束。
2. **演义线**：按 `05_榜单/` 读十三杰、四猛、四绝、十八好汉，再回人物与事件。
3. **神魔线**：从 `03_神魔/` 的星宿映射进入，看神魔事件、法宝、神域、十三关。

## 势力地图

- 15 个关键节点：581 隋代周 → 630 灭东突厥
- 34 条动向箭头：主将、兵力、路线、结果
- 真实经纬度 + 府级边界（204 个单元）
- 28 个域外势力 + 108 条反王/烟尘
- 5 个“推测势力范围”（千突厥、铁木耳、吴可宣、李执、高士远）
- 地图底图需联网；势力范围/边界为历史或推测示意，不作边界依据

## 口径

> [!warning]
> 史实 / 小说评书 / 神魔传说 / IP 原创 分轨标注；版本冲突不强行合并。  
> “神魔大隋唐”是当代评书/巡演体系，不是固定原书；金锁十三关的具体关卡为 IP 改编。  
> 反王/烟尘名单不唯一；月份可考者标月，不可考者标“不详”。
