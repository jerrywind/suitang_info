# 版本冲突

> [!warning]
> 冲突不是错误，是不同传统的“活口”。改编时选一条主版本，其余写成“说书人/民间传说/戏台演出”。

| 争议点 | 本资料的处理 |
|---|---|
| 十三杰第 12—13 席 | 秦琼、尉迟恭并称；部分版本以左天成、杨义臣、秦用、丁彦平替换 |
| 四猛成员 | 主榜罗士信、来护儿、新文礼、秦用；另有王伯超等版本 |
| 四绝成员 | 主榜罗松枪法、程咬金斧法、侯君集轻功、尚师徒四宝；另有秦琼交友、杨广荒淫等版本 |
| 李元霸之死 | 《说唐》雷击；《兴唐传》鱼俱罗拖刀计；两种都保留 |
| 罗成之死 | 主流为淤泥河万箭穿心；《隋唐演义》结局较温和；历史原型罗士信死于洺水 |
| 裴元庆之死 | 《说唐》庆坠山火雷阵；《兴唐传》聂世雄飞刀；《瓦岗英雄》归隐 |
| 罗士信之死 | 《兴唐传》新月娥陷坑；《瓦岗英雄》扬州陷阱；历史为洺水被俘杀 |
| 四平山/四明山 | 版本异名；本资料统一写“四平山（四明山）”，并保留两说 |
| 李元霸/宇文成都本相 | 主流：李元霸=金翅大鹏，宇文成都=雷声普化天尊（闻仲）；另有把李建成与雷尊混写的版本 |
| 青龙三世 | 苏宝同与薛刚两说；本资料并列，不强行二选一 |
| 神魔大隋唐的“正典” | 孙天啸版本是当代评书/巡演体系，剧情会随现场调整；本资料把它当“活文本” |
| 李元霸死亡与雷劫 | 传统星宿说：杀雷尊→雷劫；《兴唐传》：鱼俱罗拖刀计。两者可并存为“史实/传说”双轨 |
| 白虎三投唐 | 罗成→薛仁贵→郭子仪；另有薛刚为青龙三世的版本 |
