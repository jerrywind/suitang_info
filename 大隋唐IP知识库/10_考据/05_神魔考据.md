# 神魔考据

> [!warning] 先分清三层
> **传统星宿说** / **当代评书** / **IP 原创**。不要把原创当原书，也不要把当代评书当固定正典。

## 关键边界

- 《说唐》星宿系统：紫微/二十八宿/三十六天罡；李元霸=金翅大鹏、宇文成都=雷声普化天尊、裴元庆=哪吒、秦琼=左天蓬、尉迟恭=黑煞星、单雄信=青龙、罗成=白虎、程咬金=闻土星。
- 孙天啸《神魔大隋唐》：公开介绍提到李元霸宿世因果、魏文通玉泉山学刀、关公英灵传艺、智者大师度化、金锁坠地十三关、美良川单鞭斗唐将、玄武门；猪八戒与秦琼、尉迟恭同台。具体剧情以现场/授权文本为准。
- IP 原创：金锁十三关的具体关卡、神魔规则、三端玩法。
