# 道门

> [!quote]
> “天地不仁，以万物为刍狗；我偏要教几个徒弟。”

> [!abstract] 速览
> - **领袖**：元始天尊 / 紫阳真人 / 黎山老母
> - **界域**：昆仑—终南山—黎山—蓬莱
> - **主色 / 徽记**：青、紫、白；太极 + 雷纹

传艺、法宝、变化、兵法、散仙网络
