# 军马与马政

> [!quote]
> 名将骑的是名马，军队骑的是“能跑、能驮、能活”的马。  
> 一支部队没有马，最多走得慢；没有驮马，会直接饿死。

## 马政：国家怎么养马

- 太仆寺掌厩牧、车马、驿传；唐代马政以陇右牧监为核心。
- 《唐会要》载：贞观初仅得牝牡三千，徙之陇右；麟德中增至七十万六千匹，置八使、四十八监。
- 马政不只是养马：马籍、牧监、草场、种马、驿传、淘汰、军需，是一整套国家系统。
- 战马与驮马、驿马、民马分开管理；不是所有马都能上阵。

> [!info] 《唐会要》的关键数字
> 贞观初“仅得牝牡三千”，徙之陇右；麟德中增至“七十万六千匹”，置八使、四十八监，跨陇右、金城、平凉、天水四郡，后扩展到河曲。  
> 这不是“马多”，是制度、草场、种马、马籍、驿传一起转起来。

## 马具与马铠

| 马具 | 作用 |
|---|---|
| 鞍 | 骑乘稳定；高桥鞍适合长距离/冲锋 |
| 镫 | 骑手借力，提升马上格斗稳定性 |
| 衔/镳 | 控马；战马需要“听缰”而非只靠鞭 |
| 马铠 | 具装战马防护；牺牲速度/耐力 |
| 蹄铁 | 长途/硬地保护马蹄；影响行军成本 |

## 四层用马

1. **战马**：冲锋/骑射，选自牧监/贡马。
2. **驿马**：传递军情/诏令，耐力优先。
3. **驮马**：粮草/甲械，负重优先。
4. **民马**：府兵自备/民间征发，参差但量大。
