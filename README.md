## 快速开始

### 阅读

1. 用 **Obsidian** 打开 `大隋唐IP知识库/`。
2. 从 [首页](大隋唐IP知识库/00_入口/00_首页.md) 进入。
3. 想看势力地图：打开 [大隋唐势力地图与动向图.html](大隋唐势力地图与动向图.html)（浏览器打开；底图需联网）。

### 重建

在仓库根目录运行：

```powershell
python scripts/obsidian_build.py
python scripts/build_map_html.py
```

- `obsidian_build.py`：重写 `大隋唐IP知识库/` 的 Markdown、MOC、索引、颜色卡、反王表与根 README。
- `build_map_html.py`：重写 `大隋唐势力地图与动向图.html`。
- 只有更新 cn-atlas 府级边界时，才需要先运行 `python scripts/build_pref_assets.py`（依赖 `assets/cn_prefectures.json`）。

## 势力地图

- **15 个关键节点**：581 隋代周 → 630 灭东突厥
- **34 条动向箭头**：主将、兵力、路线、类型、结果
- **真实经纬度**：城市、河流、山脉、府级边界（204 个单元）
- **28 个域外势力**：草原、西域、东南亚、印度，可分组开关
- **108 条反王/烟尘**：按节点筛选活跃者，紫色=反王、橙色=烟尘、淡色=终年不详
- **5 个推测势力范围**：千突厥、铁木耳、吴可宣、李执、高士远，紫色淡面 + “推测”标签
- **标签自动排布**：所有标签保留，重叠时向外找空位并画引线
- **显示选项**：争夺区虚线、撤退/袭扰点线、标签自动排布，可分别开关

> [!warning] 地图口径
> 底图需联网（Leaflet + OpenTopoMap / Esri Physical）。  
> 势力范围、反王位置和推测范围是历史/战略示意，不是精确边界；不按现代国界解释。  
> 反王/烟尘中，能核实者精确到月；终月不详者明确标“不详”，未硬编。

## 已知限制

- 底图瓦片需联网；府级边界已内嵌，不依赖第二次网络请求。
- `scripts/` 下少数旧脚本可能被编辑器/预览占用而无法删除；归档副本已存在，原文件不参与构建。
- 历史疆域没有免费、精确到 581—630 年的公开 GIS；中原势力用真实府级边界细化，历史范围仍是示意。
